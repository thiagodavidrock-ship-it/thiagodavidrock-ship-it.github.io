Política de Privacidade / Privacy Policy

Última atualização / Last updated: 2026-10-09

Português

Esta política descreve como o aplicativo n8n canais ("o aplicativo") trata dados obtidos por meio dos Serviços de API do YouTube. O aplicativo é uma ferramenta de uso pessoal, executada no computador do desenvolvedor, usada apenas nos canais do YouTube que pertencem ao desenvolvedor.

O aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Os dados também são tratados conforme a Política de Privacidade do Google.

Dados acessados

  • Informações básicas do canal autorizado (ID, nome).
  • Vídeos, thumbnails e metadados (título, descrição, tags, status) enviados ou editados pelo próprio aplicativo.
  • Estatísticas de desempenho do canal autorizado (YouTube Analytics).
  • Tokens de autorização OAuth fornecidos pelo Google.

Como os dados são usados

  • Publicar e gerenciar vídeos no canal autorizado.
  • Analisar o desempenho do próprio canal para planejar os próximos vídeos.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento e compartilhamento

  • Os dados e tokens ficam armazenados somente no computador do desenvolvedor; não há servidor externo.
  • Os dados não são vendidos, compartilhados nem transferidos a terceiros, nem usados para publicidade.
  • Não são usados cookies nem rastreamento.

Retenção e exclusão

  • Estatísticas são mantidas apenas enquanto úteis para o planejamento do canal e podem ser apagadas a qualquer momento.
  • Você pode revogar o acesso do aplicativo a qualquer momento na página de permissões da sua Conta Google: https://security.google.com/settings/security/permissions. Após a revogação, os tokens armazenados deixam de funcionar e são apagados.
  • Para pedir a exclusão de qualquer dado, use o contato abaixo.

English

This policy describes how the n8n canais application ("the app") handles data obtained through the YouTube API Services. The app is a personal-use tool running on the developer's own computer, used only with YouTube channels owned by the developer.

The app uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Data is also handled according to the Google Privacy Policy.

Data accessed

  • Basic information about the authorized channel (ID, name).
  • Videos, thumbnails and metadata (title, description, tags, status) uploaded or edited by the app itself.
  • Performance statistics of the authorized channel (YouTube Analytics).
  • OAuth authorization tokens issued by Google.

How data is used

  • To publish and manage videos on the authorized channel.
  • To analyze the channel's own performance to plan future videos.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and sharing

  • Data and tokens are stored only on the developer's computer; there is no external server.
  • Data is not sold, shared or transferred to third parties, and is not used for advertising.
  • No cookies or tracking are used.

Retention and deletion

  • Statistics are kept only while useful for channel planning and can be deleted at any time.
  • You can revoke the app's access at any time via your Google Account permissions page: https://security.google.com/settings/security/permissions. After revocation, stored tokens stop working and are deleted.
  • To request deletion of any data, use the contact below.

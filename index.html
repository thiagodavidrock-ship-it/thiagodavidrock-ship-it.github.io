Português

n8n canais é uma ferramenta de uso pessoal, executada no computador do próprio desenvolvedor, que automatiza a produção e a publicação de vídeos nos canais do YouTube que pertencem ao próprio desenvolvedor.

Com a autorização do dono do canal (login do Google), a ferramenta usa os Serviços de API do YouTube para:

  • enviar vídeos e thumbnails para o canal autorizado;
  • preencher título, descrição, tags e configurações dos vídeos;
  • ler estatísticas de desempenho do próprio canal (YouTube Analytics) para melhorar os próximos vídeos.

A ferramenta não é oferecida ao público, não acessa canais de terceiros e não vende nem compartilha dados. Ela usa os Serviços de API do YouTube e está sujeita aos Termos de Serviço do YouTube.

English

n8n canais is a personal-use tool, running on the developer's own computer, that automates the production and publishing of videos to YouTube channels owned by the developer.

With the channel owner's authorization (Google sign-in), the tool uses the YouTube API Services to:

  • upload videos and thumbnails to the authorized channel;
  • set video title, description, tags and settings;
  • read the channel's own performance statistics (YouTube Analytics) to improve future videos.

The tool is not offered to the public, does not access third-party channels, and does not sell or share any data. It uses the YouTube API Services and is subject to the YouTube Terms of Service.
